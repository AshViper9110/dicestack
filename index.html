HOW TO PLAY

ルール

目的・勝利条件

次のどちらかを満たすと勝利です。①ゴール到達：自分のダイスが相手の初期配置列の両端のゴールマス（白はA1/E1、黒はA7/E7）に到達する。②全スタック：相手のダイス3個すべての上に自分のダイスを置く。

移動

自分のターンに、スタックの最上段にある自分のダイスを選択し、上下左右または斜めに1マス移動します。移動成功時、数字は 1 → 2 → 3 → 1 と変化します。

スタック

相手のダイスがあるマスには、数字を更新した後の自分の数字が、相手の最上段の数字より大きい場合のみ移動できます。相手のダイス1個をスタックしただけでは勝利にならず、3個すべてを覆うと勝利です。自分のダイスの上には積めません。

オンライン対戦

ホストが白、ゲストが黒です。ホストがゲーム状態を検証・管理し、ゲストは移動要求を送ります。Peer IDを相手と共有してください。

GitHub Pagesで公開

index.html、style.css、script.jsをリポジトリのルートに置いてpushし、Settings → Pages → Deploy from a branch → main / (root) を選択します。HTTPSの公開URLを開いて対戦してください。

通信接続の確立にはPeerJSの公開シグナリングサーバーを利用します。ネットワーク環境によっては接続できない場合があります。
